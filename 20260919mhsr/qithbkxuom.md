# 河北省生殖医院精子库供精申请要求公示，捐精有学历要求

> 更新时间：2026-09-19 (UTC+8)

河北省人类精子库设立在河北省计划生育科学技术研究院，符合供精者基本条件的志愿者，需要携带身份证、学生证或毕业证原件，经审核基本条件合格后签署《供精知情同意书》再进行首次精液筛查，其中供精者的基本条件之一就是必须原籍为中国公民。

河北省生殖医院建立有河北省唯一的一家精子库，而河北省精子库主要目的之一就是接受捐精，据了解，2023河北省生殖医院精子库对供精者的最新要求就是年龄要在20-40周岁，学历要为大专及以上，且是身高170cm以上的中国公民，不能有乙肝、色盲、性传播疾病史，也不能有遗传病史和遗传病家族史等等。
河北省计划生育科学技术研究院（河北省生殖医院）2011年开始积极筹备河北省人类精子库，同年12月13日正式获批试运行河北省人类精子库。河北省人类精子库的建立，可有效地解决无精子症患者的生育需求，同时也为从事高危职业的男性预先储存精子，解决他们生育的后顾之忧。
河北省人类精子库位于石家庄市新华区和平西路480号，捐精不仅要对捐献者进行精液检查、血液分析、染色体检测、优生检测、传染病筛查等，还需要满足以下要求：

- 1. 供精者必须原籍为中国公民；
- 2. 年龄在20～40周岁，大专及以上学历，体重指数（BMI）≤28，身高170cm以上；
- 3. 身体健康，五官端正，智力正常，无长期接触放射线和有毒有害物质，无不良嗜好；
- 4. 能手淫取精；
- 5. 无乙肝、色盲、性传播疾病史，无遗传病史和遗传病家族史；
- 6. 停止供精后6个月能来精子库进行复查；
- 7. 第一次前来精子库需禁欲3~5天，携带身份证、学生证或毕业证原件。

在河北省精子库经审核基本条件合格后，需要签署《供精知情同意书》，录入个人相关信息，然后进行首次精液筛查，经检测，精液质量达到卫生部关于供精者精液质量标准后，会通知再次进行精液检查，两次精液检查合格后抽血化验及体检，所有检查及化验均合格，才能成为合格的供精者，进入正式捐精程序，完成全部捐精流程还获得6000元现金补贴。
